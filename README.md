# Список задач

Добавляйте задачи, отмечайте их выполнение и удаляйте из списка.
Задачи и отметки сохраняются в localStorage текущего браузера.

## Запуск

Откройте index.html в браузере или запустите локальный сервер из папки проекта:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Для публикации на GitHub Pages укажите ветку main и папку / (root).

## Инструменты

HTML, CSS и JavaScript без зависимостей и сборки. OpenAI Codex использовался для разработки интерфейса, написания кода и проверки сценариев.
